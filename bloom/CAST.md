# 路灯泛光色偏：核宽—通道模型、JND 反解与实测

投诉现象：夜间路灯灯芯是白的（三通道相等），光晕却偏黄。白色光源的光晕不该
与光源异色。偏黄 = 光晕里蓝通道相对衰减更大，即泛光在三个通道上衰减不一致。
本文给出三通道衰减表达式、色偏定义、由可察觉阈值反解的核宽上限，以及三档光源
强度下的实测数据。对应程序 `src/bloomcast.c`，自检 `make test`。

## 1. 三通道各自的泛光衰减表达式

### 1.1 衰减由模糊核决定

线性 HDR 下，通道 c（c ∈ {R,G,B}）先过 bright-pass，再被模糊核扩散。设
bright-pass 后的通道能量为 E_c，模糊核为 k(·; w_c)，w_c 是该通道的核宽，则
光晕在距灯芯 d 处的强度（单位尖刺响应，即可分离二维核值）为

```
H_c(d) = E_c · f(d; w_c),   f(d; w) = (k * k)(d; w)
```

f 是一维核经可分离卷积得到的二维核值。能量守恒只保证**全平面**积分不变，不
保证任一距离 d 上的强度不变：核越宽，同一 d 处分到的强度越低。通道间核宽不
同，同一 d 处的 H_c 就不同——这就是色偏的来源，与灯芯本身的颜色无关。

程序用三角（tent）核，它是两次盒式模糊的极限，也是 bloom 逼近高斯的标准核。
半径 r、核宽 w = 2r+1，一维权重

```
k(a; w) = (w − |a|) / Z(w),   Z(w) = (3w² + 1)/4
```

Z(w) 在整数宽处严格等于权重和 w² − r(r+1)（r=2 时 19），核精确归一；分数宽
时 Z(w) 连续，实测核在整数宽处与解析式逐像素相等（自检
`spike_center_matches_law`、`spike_ring_matches_law`）。

### 1.2 核宽按亮度加权 ≡ 按通道拉伸

若核宽按该通道的 bright-pass 亮度（能量）加权，就是给每个通道一个不同的拉伸
因子。以三通道平均能量 E0 = mean(E_c) 为基准，核宽—通道关系写成

```
w_c = w0 · (E_c / E0)^γ
```

- γ = 0：w_c ≡ w0，统一核宽，通道间不拉伸；
- γ = 1：核宽与通道能量成正比，即“按亮度加权”；
- γ 越大拉伸越狠。γ 是把“按通道加权”连续化出来的旋钮，方便反解上限。

灯芯被裁成纯白（三通道相等），但灯芯外的光谱衰减 R/G 保留多、B 保留少
（实测谱形 `SPECT = {1.000, 0.985, 0.910}`），于是 E_B < E_G < E_R，代入上式
得 w_B < w_G < w_R：蓝通道核最窄。

### 1.3 为什么偏黄出现在外环

二维峰值（d=0）随核宽的主项是 1/w²：窄核在中心更集中，所以**灯芯附近**蓝色
反而偏强；但在核尾部主导的**外环**（程序取切比雪夫距离 d=2 的环），窄核的
尾部先归零，蓝通道在 d=2 处分到的强度最低。人眼看到的“光晕”是外环而不是
灯芯，因此观感为蓝亏、即偏黄。色偏一律在 d=2 外环测量（`HALO_D=2`）。

## 2. 色偏量：三通道强度比偏离 1:1:1 的程度

白色光源要求光晕三通道强度比为 1:1:1。令三通道光晕均值
H̄ = mean_c H_c，定义通道 c 的色偏量

```
cast_c = H_c / H̄ − 1
```

即“该通道实测强度相对三通道均值的比值减一”。cast = 0 为无色偏；B 通道
cast_B < 0 就是蓝亏（偏黄），R 通道 cast_R > 0 就是红盈。三档里最差的
|cast_c| 作为该配置的色偏指标，记为 cast_worst。

## 3. 用 JND 反解三通道核宽的最大差异

可察觉阈值取 EPS = 0.05（5%）。要求 cast_worst ≤ EPS。

### 3.1 闭式解（峰值律，设计上限）

对等能量白色尖刺，令三通道核宽相对基准对称拉伸：
w_R = w0(1+δ)，w_G = w0，w_B = w0(1−δ)。二维峰值主项 ∝ 1/w²，一阶展开下
cast 的主项为 2δ，令 2δ = EPS 得闭式相对展宽

```
δ* ≈ EPS / (2 − EPS) = 0.05 / 1.95 = 0.02564
```

对应的三通道核宽最大**绝对**差异（基准 w0 = 5 px）

```
Δw_max = w0·(1+δ*) − w0·(1−δ*) = 2·w0·δ* = 0.256 px
```

程序对精确 tent 核做二分反解（`jnd_spread_numeric`），峰值环实测
δ_peak = 0.02537，与闭式解偏差 1.1%（自检 `jnd_peak_matches_closed_form`）。
外环因混合了多个核偏移、对核宽差异更钝，实测 δ_ring = 0.04844
（Δw = 0.484 px），比峰值宽松；**峰值闭式解是更紧的设计极限，按它取值**。

### 3.2 超过上限就用统一核宽再合成

判定规则：每帧由实测 E_c 算出 w_c，若

```
(wmax − wmin) / wmean  >  2δ*      （或 cast_worst > EPS）
```

则放弃按通道加权，令 w_c ≡ w0 重新合成（γ = 0）。统一核宽下 f(d;w) 对三
通道完全相同，H_c 之比 = E_c 之比，残余色偏只来自光源自身谱形、不再被核
放大。三档实测中统一核宽的 cast_worst 分别为 4.28% / 4.27% / 3.96%，全部
达标（自检 `uniform_recomposite_passes`）。

## 4. 取舍：色偏曲线与高光层次曲线共同定核宽

两条曲线都以相对核宽展宽 spread = (wmax−wmin)/wmean 为横轴（数据见
`../artifacts/bloomcast_curves.csv`，图见
`../artifacts/bloomcast_curves.png`）：

| 方案 | 高光层次 | 颜色准确性 |
|---|---|---|
| 按通道加权（γ 大，spread 大） | 亮通道核更宽、高光铺得更开，层次自然 | 核宽差异被尾部衰减放大成色偏 |
| 统一核宽（γ=0，spread=0） | 三通道同宽，高光层次少 | H_c 之比 = E_c 之比，颜色最准 |

- 曲线 A（色偏 vs spread）：三档强度各一条，叠加 JND=0.05 线，给出每档允许
  的 spread 上限；
- 曲线 B（高光层次 vs 色偏，中档灯）：spread 本身就是层次旋钮，阴影区为
  可达标区，空心圆标出 JND 限制下的最大可用 spread。

定核宽的方法：在曲线 A 上找到本档强度与 JND 线的交点，反推 γ_max（程序二分
给出）；工作点 γ 取不超过 γ_max 的最大值——在色偏达标的前提下吃满高光层次。

## 5. 三档光源强度实测

场景：16×16 暗场，中心灯芯裁成纯白（三通道相等），d=1/2 衰减环带谱形失衡，
阈值 0.15，基准核宽 w0=5。每档给 γ=1（按亮度加权）与 γ=0（统一核宽）两组
三通道实测能量 E、核宽 w、外环光晕 H 与色偏 cast。

### 低档 L=2 —— 不达标，须回退统一核宽

γ_max = 0.257，对应 Δw_max = 0.106 px；γ=1 时 spread=0.0818，cast_worst=7.05% > 5%。

### 结论

1. 三档里低、中两档在 γ=1 下色偏超标，超标的共同特征是蓝通道核宽被压到
   4.75 px（基准 5.00），外环蓝亏 7.05% / 5.68%；回退统一核宽后降到 4.28% /
   4.27%，达标。
2. 高档灯因亮部能量大、bright-pass 后通道能量比反而更接近，γ=1 仍在 JND
   内，可保留按通道加权的高光层次。
3. 工程取值：核宽差异先按峰值闭式上限 Δw ≤ 2·w0·EPS/(2−EPS) ≈ 0.256 px
   （w0=5）兜底，再按各档 γ_max 收紧；越界即统一核宽再合成。
