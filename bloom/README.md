# bloom

`make test` 跑自检（`bloom` 原模块 + `pyramid` 多级降采样与帧预算基准）。

## 文件

- `src/bloom.c` — bright-pass 与全分辨率可分离盒式模糊（原实现）。
- `src/pyramid.c` — 多级降采样金字塔、闭式代价表、三档光晕半径帧预算基准。
- `../artifacts/pyramid_curves.html` — 总代价–光晕范围双曲线图（含数据表）。

## 代价模型

第 k 级像素数 N_k = N₀/4ᵏ，核宽 w = 2r+1，模糊代价 C_k = N_k·w（可分离的
公共因子 2 省略）。m 级总代价是等比级数：

```
T(m) = N₀·w · Σ_{k=0}^{m-1} 4⁻ᵏ = (4/3)·N₀·w·(1 − 4⁻ᵐ)
```

渐近总代价 T∞ = 4N₀w/3，新增第 m 级在有限总和中的边际贡献：

```
3 / (4ᵐ − 1)
```

按「每级贡献不低于总代价 5%」反解：3/(4ᵐ−1) ≥ 0.05 → m ≤ log₄61 ≈ 2.97，
即最高三级；m=3 末级占 4.76% 正落在膝点，m=4 仅 1.18%，被规则拒绝。

## 实现要点

- level 0 只做 bright-pass 不做全分辨率模糊（最大头），模糊从 level 1 起。
- 上采样利用双线性插值的线性性：`up(L1 + up(L2)) = up(L1) + up²(L2)`，
  单条加法链与逐级独立上采样结果逐位相同，上采样代价由 O(m·N₀) 降到 4N₀/3。
- 各等权 1/m 合成，权重和为 1，平场能量守恒（自检 `flat_energy_kept`）。

## 帧预算基准

火焰图锚点：现状 m=3、r=4、全级模糊占整帧 40%，故非后处理代价
G = 1.5 × 后处理现状，25% 预算要求后处理 ≤ G/3。预算按 tap 操作数模型判定
（GPU 与 tap 数成比例），主机墙钟时间仅作参考（CPU 受带宽主导）。

| 预设 | m | r | 后处理占比 | 模型范围 | 预算 | 范围 |
|---|---|---|---|---|---|---|
| current_r4_m3（现状） | 3 | 4 | 40.00% | — | FAIL | — |
| small_r1_m3 | 3 | 1 | 16.46% | 4 px | PASS | PASS |
| medium_r1_m4 | 4 | 1 | 17.07% | 8 px | PASS | PASS |
| large_r1_m5 | 5 | 1 | 17.22% | 16 px | PASS | PASS |

光晕范围模型：最粗级 texel 在全分辨率下的覆盖半径 r·2ᵐ⁻¹；脉冲实测足迹
（1% 自身峰值，11/25/52 px）验证单调扩散，偏大来自多级盒式模糊的累积展宽。
