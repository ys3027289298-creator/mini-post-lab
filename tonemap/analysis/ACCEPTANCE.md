# 暗部细节 / 对比度可执行验收判据

把验收语句「暗部不能死黑，要能看清细节」变成两个可计算、可划线的指标，
推出同一条压缩曲线下两者的解析权衡关系，反解参数可行区间，比较三种曲线
形状的权衡前沿，并给出动态范围不可行阈值。

代码与数据：

| 文件 | 作用 |
|---|---|
| `metrics.py` | 场景模型、三种曲线、D/C 的解析公式与经验（直方图）测量 |
| `frontiers.py` | 权衡前沿、参数区间反解、支配判定、DR 阈值求根 |
| `run_analysis.py` | 三档场景 × 三种曲线的完整验收运行，落盘 JSON |
| `make_figures.py` | 三张图（曲线形状 / 权衡前沿 / 不可行阈值） |
| `test_metrics.py` | 39 项可执行检查（`python3 test_metrics.py`） |
| `outputs/acceptance_run.json` | 最近一次运行的全部数值 |

---

## 1. 场景模型

场景亮度记为 x，动态范围 R = x_max / x_min（档数 = log₂R）。归一化到
u ∈ [0, 1]，采用**对数均匀**密度（每一档承载等量内容，色调映射的标准
最坏情形）：

```
x(u) = R^(u−1),   u ~ Uniform(0, 1),   x ∈ [1/R, 1]
```

色调曲线 T: u ↦ y ∈ [0, 1]，三族候选都满足单调、端点固定 T(0)=0、T(1)=1、
趾部斜率 ≤ 1（压暗部的正常色调映射制度）。

---

## 2. 两个度量的表达式

### 2.1 暗部细节 D —— 亮度直方图最低两成区间的非空桶比例

取**暗部人群**（场景亮度最低两成的输入质量，即 u ∈ [0, 0.2]，恰好是验收
语句所指「暗部」的内容），在输出 [0, 1] 上等宽分 B 个桶，统计落入输出
最低两成区间 [0, 0.2] 的非空桶：

```
        非空桶数（暗部人群在输出 [0,0.2] 内）
D = ─────────────────────────────────────────── ,   D ∈ [0, 1]
                    B/5
```

连续极限下非空桶比例 = 占据宽度比例。对单调曲线，暗部人群的输出是一个
区间 [0, T(0.2)]，故

```
D = min(T(0.2), 0.2) / 0.2 = 5 · min(T(0.2), 0.2)
```

**为什么不直接对整幅图的输出直方图数空桶（字面读法）**：对连续内容上的
单调曲线，最低桶永远非空（T(0)=0 附近总有像素），于是「最低两成的非空桶
比例」恒接近 1，哪怕曲线把暗部压成死黑也测不出来。`test_metrics.py` 第 7
组用 γ=8 的极端曲线实证：暗部人群口径 D=0.01（检出死黑），整图直方图口径
仍为 1.00（失明）。字面口径只对「像素数少于桶数」的稀疏图像有意义，因此
本判据以暗部人群为度量总体；若项目要求保留字面口径，两者在 JSON 中同时
输出（`D_empirical` 与 `literal_wholehist_D`）。

### 2.2 整体对比度 C —— 九成分位点与一分位点之比

```
C = Q_0.9(y) / Q_0.1(y)
```

对数均匀输入下，输入分位点就是 u 的分位点（Q_p(u)=p），因此
Q_p(y) = T(p)，C = T(0.9)/T(0.1)。

### 2.3 验收线（把「多暗/多清楚」钉成数字）

| 阈值 | 取值 | 含义 |
|---|---|---|
| D* | 0.75 | 暗部人群必须填满输出暗区 75% 的桶（留出 25% 纯黑余量） |
| C* | 4 | Q0.9/Q0.1 不低于 4（温和底线；三族曲线在线性端点 C=9） |
| G | 40 | 暗部平均线性光增益预算（显示链路噪声/色阶预算，见 §6） |

## 3. 三种曲线与解析权衡关系

### 3.1 幂函数 y = u^γ（γ ≥ 1）

```
D(γ) = 5·(0.2)^γ
C(γ) = 0.9^γ / 0.1^γ = 9^γ
```

消去 γ（γ = ln(5/D)/ln 5）得到权衡曲线：

```
                    ln(5/D)
C_power(D) = 9 ^  ───────────
                     ln 5
```

### 3.2 凸对数 y = 1 − ln(1 + α(1−u)) / ln(1+α)（α > 0）

输出端对数，α→0 时趋于线性。D、C 为同一参数 α 的解析函数（代码直接求值）：

```
D(α) = 5 · [1 − ln(1+0.8α)/ln(1+α)]          （截断在 1）
C(α) = [1 − ln(1+0.1α)/ln(1+α)] / [1 − ln(1+0.9α)/ln(1+α)]
```

形状有界：C ∈ [9, 21.85)。C 的上确界（α→∞）为 ln 10 / ln(10/9) ≈ 21.854。

### 3.3 分段线性，拐点固定在输入五分位 (0.2, y_b)，y_b ∈ (0, 0.2]

```
        ⎧ 5 y_b · u,                 u ≤ 0.2
T(u) =  ⎨
        ⎩ y_b + (1−y_b)/0.8 · (u−0.2), u > 0.2
```

- Q0.1 在趾段：T(0.1) = 0.5 y_b
- Q0.9 在肩段：T(0.9) = 0.875 + 0.125 y_b

```
D(y_b) = 5 y_b
C(y_b) = (0.875 + 0.125 y_b)/(0.5 y_b) = 1.75/y_b + 0.25
```

消去 y_b（y_b = 0.2 D）：

```
C_PL(D) = 8.75/D + 0.25
```

### 3.4 共同结构：抬暗部必降对比度

三族曲线都由单参数控制，D 随参数单调下降、C 随参数单调上升，因此 C(D)
都是 D 的单调递减函数——这就是「抬暗部必然发灰、压暗部必然丢细节」的
解析形式。前沿图见 `outputs/fig2_frontier.png`。

## 4. 参数可行区间反解

约束 D ≥ D* 与 C ≥ C* 各自给出参数的一侧边界，求交集并与曲线的合法域
相交：

| 族 | D 约束边界 | C 约束边界 | 可行区间 |
|---|---|---|---|
| power | γ ≤ ln(5/D*)/ln 5 | γ ≥ ln C*/ln 9 | [max(1, ln C*/ln 9), ln(5/D*)/ln 5] |
| PL | y_b ≥ 0.2 D* | y_b ≤ 1.75/(C*−0.25) | 与 (0, 0.2] 求交 |
| log | α ≤ α(D*)（数值求根） | α ≥ α(C*)；C* > 21.854 时无解 | 两边界求交 |

交集为空即形状层面不可行（例如 power 在 D*=0.98、C*=30 时无解；log 在
C* 超过其上确界时无解）。在 D*=0.75、C*=4 下三族的实际区间：

```
power γ ∈ [1.000, 1.179]      PL y_b ∈ [0.15, 0.20]      log α ∈ [~0, 1.070]
```

工作点统一取 D=D* 边界（在刚好通过暗部规则的前提下对比度最大）：
γ*=1.17875，y_b*=0.15，α*=1.06964。

## 5. 三种形状的权衡前沿与支配比较

在公共 D 网格上逐点比较 C（`frontiers.dominance_table`，400 点数值核验）：

| 结论 | 证据 |
|---|---|
| **幂函数弱支配分段线性** | 全 D ∈ (0,1) 有 C_power(D) > C_PL(D)，仅 D=1 端点重合（同退化为线性） |
| **幂函数弱支配凸对数** | 全内部点严格占优；对数的 C 被限制在 [9, 21.85]，幂函数无此上界 |
| 分段线性 vs 对数 | 在 D≈0.88 附近交叉，互不能支配 |

幂函数处处不劣于另外两种（内部严格更优），**支配者是幂函数 y=u^γ**。
直觉：幂函数把斜率预算连续地按 u^(γ−1) 分配，而 PL 把全部压暗集中在一个
折点、对数在趾部浪费了过多斜率，两者在「同样暗部层次」下都留不下幂函数
那么多的中段/亮段对比。工作点处的数值对比：D=0.75 时
C_power=13.33 > C_PL=11.92 > C_log=11.79。

## 6. 动态范围不可行性阈值

### 6.1 为什么需要第二个物理约束

D、C 是纯形状指标：任何 R 都能选一条曲线满足 D*（形状区间与 R 无关）。
但把很窄的一线性光区间撑到输出宽度 0.2D* 需要**增益**，增益受显示链路
噪声/色阶限制。暗部人群 u ∈ [0, 0.2] 对应的线性光跨度

```
Δx = R^(−0.8) − R^(−1) = R^(−1)·(R^0.2 − 1)
```

平均暗部增益（输出宽度 / 输入光跨度）：

```
g(R, D) = 0.2 D / Δx = 0.2 D · R / (R^0.2 − 1)
```

### 6.2 阈值表达式

要求 g(R, D*) ≤ G，整理为

```
R ≤ A (R^0.2 − 1),   A = 5G / D*
```

函数 f(R) = R − A(R^0.2 − 1) 在 R=1 附近为正、中段为负、在大 R 处再次过零，
第二个根即阈值 R*，由二分法数值求出：

```
R* = 大根 of  R = (5G/D*) · (R^0.2 − 1)
```

大预算闭式估计（R^0.2 ≫ 1 时 R ≈ A·R^0.2 ⇒ R^0.8 ≈ A）：

```
R* ≈ (5G/D*)^1.25
```

R > R* 时 g(R, D*) > G：**无论用三种曲线中的哪一种，D ≥ D* 与增益预算
G 都不可能同时满足**——约束交集为空的原因是场景动态范围超限，不是曲线
没调好。阈值随预算的曲线见 `outputs/fig3_threshold.png`。

### 6.3 本项目数值（D*=0.75, G=40）

```
R* = 730.3 ≈ 9.51 档   （闭式估计 1077.6，偏保守 1.48 倍）
```

## 7. 三档场景验收结果

`python3 run_analysis.py`（100 万采样点、500 桶；解析 D 与经验 D 完全一致，
C 误差 < 1.3%）：

| 场景 | R（档数） | 所需增益 | 幂函数 | 对数 | 分段线性 | 结论 |
|---|---|---|---|---|---|---|
| bright | 64（6 档） | 7.4× | D=0.750 C=13.33 PASS | D=0.750 C=11.79 PASS | D=0.750 C=11.92 PASS | 达标 |
| medium | 256（8 档） | 18.9× | D=0.750 C=13.33 PASS | D=0.750 C=11.79 PASS | D=0.750 C=11.92 PASS | 达标 |
| dark | 4096（12 档） | 143.6× | FAIL | FAIL | FAIL | **动态范围超限** |

暗档的明确结论：实际范围 4096（12 档）> 阈值 R*=730.3（9.51 档），
即使理论最优曲线也需要 143.6× 暗部增益，超过 40× 预算；三族曲线无一可行。
处置选项：放宽 D*、提高增益预算 G（阈值随 G^1.25 增长）、或在采集端压缩
场景动态范围——而不是继续调曲线参数。

## 8. 复现方式

```bash
cd tonemap/analysis
python3 test_metrics.py      # 39 项检查，全过才退出 0
python3 run_analysis.py      # 三场景验收，写 outputs/acceptance_run.json
python3 make_figures.py      # 三张 PNG 写入 outputs/
```

依赖：numpy、matplotlib（标准科学计算环境即可，无 scipy 依赖，求根为自带
二分实现）。
