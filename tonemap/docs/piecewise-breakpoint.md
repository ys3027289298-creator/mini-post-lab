# 分段点求解：规范分段曲线 vs 我们的拟合曲线

复现：`python3 tonemap/tools/piecewise_breakpoint.py`（仅标准库）。

记号：输入 `x∈[0,1]` 为归一化 HDR 亮度，输出 `y∈[0,1]` 为 SDR，8bit 量化，**一个输出级** `Δ = 1/255 ≈ 3.92e-3`。场景亮度直方图 `w(x)`（对数正态，均值 μ 为场景平均亮度），`∫w = 1`。

## 1. 两条曲线的表达式

**规范曲线（参考）**——分段：暗部线性、亮部幂函数，C⁰ 连续：

```
f(x) = k·x        0 ≤ x ≤ x_b
     = x^γ        x_b < x ≤ 1        k = x_b^(γ-1)
```

取 `γ = 1/2.2 ≈ 0.4545`、`x_b = 0.10`，则 `k ≈ 3.5112`。

**我们的现状曲线**——全局幂函数，指数按场景直方图最小二乘拟合：

```
g0(x) = x^γ̂,   γ̂ = argmin ∫ w(x)·(x^γ̂ - f(x))² dx
```

**改分段（方案 A'）**——暗段线性、亮段仍用我们的拟合幂，分段点 `t` 为待定量，交接处 C⁰ 连续：

```
g(x; t) = a(t)·x    x ≤ t
        = x^γ̂       x > t        a(t) = t^(γ̂-1)
```

## 2. 暗段 / 亮段误差表达式

按**参考分段** `[0,x_b]`（暗）、`[x_b,1]`（亮）各自累计场景加权绝对误差：

```
E_d(t) = ∫₀^x_b w·|g(x;t) - kx| dx
E_b(t) = ∫_{x_b}¹ w·|g(x;t) - x^γ| dx
```

按 `t` 与 `x_b` 的关系展开（记 `a = a(t)`）：

```
t ≤ x_b:  E_d = ∫₀^t w|a-k|x dx + ∫_t^x_b w|x^γ̂ - kx| dx
          E_b = ∫_{x_b}¹ w|x^γ̂ - x^γ| dx            （与 t 无关）

t ≥ x_b:  E_d = ∫₀^x_b w|a-k|x dx
          E_b = ∫_{x_b}^t w|ax - x^γ| dx + ∫_t¹ w|x^γ̂ - x^γ| dx
                └─ 线性错用到参考亮区, 随 t-x_b 迅速增长 ─┘
```

均匀权重下均为幂函数积分，可闭式求值（`∫x^p = x^{p+1}/(p+1)`；暗段被积函数在 `x_c = k^{1/(γ̂-1)}` 处变号，亮段在 `x = a^{1/(γ-1)}` 处变号，分段取绝对值即可）。

相对误差用各段参考输出能量归一：

```
ε_d(t) = E_d / F_d,  ε_b(t) = E_b / F_b
F_d = ∫₀^x_b w·f dx,  F_b = ∫_{x_b}¹ w·f dx
```

## 3. 等误差准则反解分段点

```
ε_d(t*) = ε_b(t*)   →   二分求解（h(t)=ε_d-ε_b 在 (0,1) 上由正转负，根唯一）
```

三档解得（详见 §7）：暗档 `t* = 0.0870`，中档 `0.0760`，亮档 `0.0980`。

注意：**等误差点 ≠ 总误差最小点** `t_opt`（暗档 0.0870 vs 0.0547）。等误差是"两段公平"准则；γ̂ 偏离 γ 越多，两者离得越远。§7 两个候选分段点即取这两个。

## 4. 反例：分段点取在暗部之外

取 `t_bad = 0.30 = 3·x_b`（中档场景）：暗段拉长到 `[0, 0.3]`，但参考亮区 `[0.1, 0.3]` 被错用线性段逼近幂函数：

| t_bad | E_dark | E_bright | E_total | 对比全局幂 E_g0 = 0.0325 |
|---|---|---|---|---|
| 0.20 | 0.0305 | 0.0321 | 0.0626 | 1.9× |
| 0.30 | 0.0409 | 0.0566 | 0.0975 | **3.0×** |
| 0.50 | 0.0512 | 0.0961 | 0.1473 | 4.5× |

亮段误差随 `t - x_b` 飙升，整体误差反而比不分段的全局幂更差。**分段点必须落在暗部内。**

## 5. 允许偏移范围（整体误差 ≤ 一个输出级）

约束 `E(t) = E_d(t) + E_b(t) ≤ Δ` 反解 `t` 的允许范围 `{t : E(t) ≤ Δ}`：

- **方案 A'（亮段用拟合指数 γ̂）：三档允许范围均为空集**——`E(t_opt)` = 0.0144 / 0.0156 / 0.0049（暗/中/亮），都越不过 1 级预算。瓶颈不在分段点而在亮段指数：由一阶展开 `|x^γ̂ - x^γ| ≈ |Δγ|·x^γ·|ln x|` 得容差

  ```
  |γ̂ - γ| ≤ Δ / S,   S = ∫_{x_b}¹ w·x^γ·|ln x| dx
  ```

  三档容差 0.045 / 0.0095 / 0.0072，而我们的 `|γ̂-γ|` = 0.113 / 0.037 / 0.009，全部超出。

- **方案 B（亮段锚定规范 γ）**：`E(x_b) = 0`，允许范围实测

  | 档 | 允许范围 | 允许偏移 |
  |---|---|---|
  | 暗 (μ=0.05) | [0.0936, 0.1067] | −0.0064 / +0.0067 |
  | 中 (μ=0.18) | [0.0916, 0.1083] | **±0.0084** |
  | 亮 (μ=0.50) | [0.0600, 0.1249] | −0.0400 / +0.0249 |

  `E(t)` 在 `x_b` 附近呈 **V 形**（斜率失配 `|a(t)-k|` 线性进入误差），故偏移量用线性估计 `δ ≈ Δ/|E'(x_b)|`：中档 `|E'| ≈ 0.470`，`δ ≈ 0.0083`，与精确反解的 ±0.0084 吻合。

## 6. 取舍：整体误差 vs 逐像素开销

开销归一：1 次 pow ≈ 20 cycle，比较+选择 ≈ 2 cycle，乘 ≈ 1 cycle，LUT 查表 ≈ 2 cycle。

| 方案 | 整体误差（暗/中/亮） | 逐像素开销 |
|---|---|---|
| 全局幂（现状） | 0.0358 / 0.0325 / 0.0092 | 20 cycle |
| 分段 A'（亮段拟合幂） | 0.0291 / 0.0189 / 0.0051 | 暗 3 / 亮 22 cycle |
| 分段 B（亮段规范幂） | ≤ 0.0039（t 在允许范围内） | 暗 3 / 亮 22 cycle |
| 分段 B + 每档 LUT | 同上 | 2 cycle（与全局幂 LUT 相同） |

**结论**：误差的瓶颈是亮段指数而非分段点位置。定方案 **B + 每档 LUT**：亮段指数锚定规范 γ，分段点取允许范围中点 `t = 0.10`（容差 ±0.0084，按最严的暗档 ±0.0065 也在范围内）；LUT（1024 项）把每像素的分支开销摊掉，逐像素成本与现状全局幂持平，代价仅是每档一次 LUT 构建和 1–4 KB 存储。

## 7. 三档实测（方案 A'，等误差准则解 t*）

| 档 | μ | γ̂ | E_g0（全局幂） | 全局幂暗部相对误差 | t* | t*−x_b | E(t*) | t_opt | E(t_opt) | 判定 |
|---|---|---|---|---|---|---|---|---|---|---|
| 暗 | 0.05 | 0.5679 | 0.0358 | 24.5% | 0.0870 | −0.0130 | 0.0291 | 0.0547 | 0.0144 | 超标 |
| 中 | 0.18 | 0.4910 | 0.0325 | 20.7% | 0.0760 | −0.0240 | 0.0189 | 0.0848 | 0.0156 | 超标 |
| 亮 | 0.50 | 0.4636 | 0.0092 | 17.6% | 0.0980 | −0.0020 | 0.0051 | 0.0962 | 0.0049 | 超标 |

全局幂在暗部的相对误差达 17–25% 且斜率非常数（规范暗段斜率恒为 k），这就是"暗部细节少"的来源。

三档 `E(t*)` 均超过 1 级预算（7.4× / 4.8× / 1.3×），且方案 A' 下允许范围为空集，任何 `t*` 都落在范围外。按要求给出各档实测误差与两个候选分段点：

| 档 | 实测 E(t*) | 候选 1：等误差点 t_eq | 候选 2：总误差最小点 t_opt |
|---|---|---|---|
| 暗 | 0.0291（超 7.4×） | 0.0870（E=0.0291） | 0.0547（E=0.0144） |
| 中 | 0.0189（超 4.8×） | 0.0760（E=0.0189） | 0.0848（E=0.0156） |
| 亮 | 0.0051（超 1.3×） | 0.0980（E=0.0051） | 0.0962（E=0.0049） |

两个候选都救不回 1 级预算——这正说明该档的失败不是分段点选错，而是亮段指数偏离规范（§5 的 |Δγ| 容差）。修正路径：亮段锚定 γ（方案 B），分段点即可落在 ±0.0084 的允许偏移内，三档达标。
