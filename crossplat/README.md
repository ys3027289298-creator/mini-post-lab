# crossplat: PC / 主机后处理一致性定位

同一套 tonemap + bloom + dof 参数，PC 正常、主机高光过曝。本模块把两条平台
profile 的差异拆成三条**互相正交**的轴，各自建模、量化、定位，并给出反解的
参数预算。

- `src/xplat_test.c`：fp16/binary16、R11G11B10F、RGBA8 的软件编解码（RNE 舍入），
  用三档已知亮度块（low L=0.05 / mid L=0.50 / high L=4.00）跑
  `曝光 → ACES → gamma 编码 → 中间缓冲往返`，按 8-bit 码值比较。
- 判据：每档块两平台输出码值差 `dq ≤ 1` 个量化级，`τ = 1/255 ≈ 3.92e-3`。

构建运行：`make test`。

---

## 1. 三条差异来源的表达式与量级

记单条链为 `O = Q_f( g( T(E·L) ) )`，其中 `T` 是 ACES，`g(x)=x^(1/γ)`，
`Q_f` 是缓冲格式 `f` 的量化往返，`E` 曝光、`L` 输入亮度。

### 1.1 浮点精度（影响极小）

每条 ALU 指令后做一次 fp16 舍入，单步相对误差有界：

```
ε16 = 2^-11 ≈ 4.88e-4（半精度机器 epsilon）
N 条指令链的累积界：|ΔO|/O ≲ N·ε16
```

实测格式网格步长（ulp，相对值）：

| x | fp16 ulp（相对） | R11G11B10F ulp（相对） | RGBA8 步长（相对） |
|---|---|---|---|
| 0.05 | 6.10e-4 | 1.95e-2 | 7.84e-2 |
| 0.50 | 9.77e-4 | 3.12e-2 | 7.84e-3 |
| 4.00 | 9.77e-4 | 3.12e-2 | 9.80e-4 |

纯精度场景（fp32 vs fp16，γ 与缓冲都相同）三档块 `dq` 全为 **0**。
fp16 的单级误差比一个量化级小约一个数量级，且浮点是相对误差——**低亮度处
绝对误差更小**，这是它与伽马误差最关键的方向区别。

### 1.2 伽马默认值（影响整个曲线）

平台默认 γ 不同时，输出差是对整条曲线的乘性偏移：

```
O_pc  = T^(1/γ_pc),   O_con = T^(1/γ_con)
O_con / O_pc = T^(1/γ_con − 1/γ_pc)
ln O_con − ln O_pc = (1/γ_con − 1/γ_pc)·ln T
```

对 γ 的灵敏度：

```
∂O/∂γ = −(ln T / γ²)·T^(1/γ)
```

T→0（低亮度，ln T 很大）时该式不趋零反而主导；T→1（高光肩区）时 ln T→0，
灵敏度趋零。**伽马误差集中在低/中亮度，高光端被 tonemap 肩区压缩掩盖。**

实测（γ 2.2 vs 2.4）：low `dq=8`、mid `dq=3`、high `dq=0`；
γ 2.2 vs 1.8：low `dq=17`、mid `dq=10`、high `dq=1`。
量级是精度误差的 10² 倍以上——整条曲线被搬动。

### 1.3 中间缓冲格式（量级介于两者之间，且带硬钳制）

| 格式 | 尾数 | 相对 ulp | 最大值 | 超界行为 |
|---|---|---|---|---|
| R16F | 10 bit | ~1e-3 | 65504 | 溢出 → Inf |
| R11G11B10F | 5/4 bit | ~3.1e-2 | **64512** | 钳到 max finite |
| RGBA8 | 定点 | ~1/255（绝对） | 1.0 | 钳到 1.0 |

R11G11B10F 无符号位、指数域 6 bit，指数字段 31 保留；最大有限值
`(2−2^-5)·2^15 = 64512`，打包码 `0x3DF`。bloom 的高亮 spike（`bloom.c` 里
单像素可达 64）若落到 R11F 缓冲，过 64512 即被硬钳，**这是高光过曝/裁切的
直接机制之一**。实测纯格式差异（R16F vs R11F）：mid `dq=2` 已超 1 级预算。
RGBA8 是绝对量化，低亮度处相对误差最大（x=0.05 时 7.8%）。

三条轴的量级排序：**伽马（~10⁰ 码值/整条曲线） ≫ 缓冲格式（~10⁰ 码值，
局部+硬钳） ≫ 浮点精度（~10⁻² 码值）**。

## 2. 定位判据：差异集中在哪一档亮度

同一输入两平台各跑一次，对每档块取码值差 `dq_k = |C_con(L_k) − C_pc(L_k)|`，
看误差随亮度的**分布形状**：

```
判据 G（伽马问题）：  dq_low ≫ dq_mid > dq_high，
                      且 ln O 对 ln L 的曲线斜率两平台不同
判据 P（精度/格式问题）：dq 随 L 增大而增大（相对误差型），
                      或在某亮度出现台阶/钳平（缓冲超界），
                      低亮度 dq 最小
```

斜率形式（对数-对数导数，区分两类误差的核心表达式）：

```
S(L) = ∂ ln O / ∂ ln L
伽马失配： ΔS = (1/γ_con − 1/γ_pc)·(∂ ln T / ∂ ln L)   ← 低亮度显著
精度问题： S 不变，只有 O 上叠加 ~N·ε16 的相对抖动        ← 全段近似平的
```

实测对照：伽马场景最大差在 **low 块**（dq=8/17）；纯精度场景三档全 0；
缓冲格式场景最大差在 **mid/high 块**（dq=2，且高端伴随钳制）。
报告里「主机高光过曝」若实测差异确实落在高端且呈台阶状，按判据 P 归到
缓冲格式/钳制；若 low 块 dq 也很大，则根因是伽马，高光只是肩区把差异
压小了的可见表象。

## 3. 用「差不超过一个量化级」反解参数预算

约束 `|ΔO| ≤ τ = 1/255`。对任意参数 `p`，一阶展开
`|ΔO| ≈ |∂O/∂p|·|Δp| ≤ τ`，反解：

```
|Δp| ≤ τ / |∂O/∂p|
```

实测反解（参考 profile：γ=2.2，E=1.0，连续输出上求导避开量化死区）：

| 块 | ∂O/∂E | 允许 \|ΔE\| | 相对 ΔE/E | ∂O/∂γ | 允许 \|Δγ\| | 相对 Δγ/γ |
|---|---|---|---|---|---|---|
| low  | 0.1730 | 0.0227 | 2.27% | 0.1562 | 0.0251 | 1.14% |
| mid  | 0.1927 | 0.0204 | 2.04% | 0.0803 | 0.0489 | 2.22% |
| high | 0.0273 | 0.1437 | 14.4% | 0.0055 | 0.7130 | 32.4% |

工程取值取**最严档（low 块）**：曝光两平台偏离必须 `≤ ~2.3%`，
伽马偏离 `≤ ~0.025`（相对 ~1.1%）。注意 high 块预算虚高（14%/32%）是
ACES 肩区灵敏度趋零造成的——那里参数怎么偏都看不出来，但也意味着**肩区
无法用于校验参数一致性**，验收只能靠 low/mid 档。

## 4. 一致性 vs 性能的取舍

两条曲线，横轴都是主机算力预算 `B`：

```
一致性误差 D(B)：随 B 单调下降
  各自优化（fp16 计算 + R11F 缓冲 + 平台默认 γ）
     → D 大（实测组合场景 low dq=17，FAIL），成本最低
  统一高精度（fp32 或强制 fp16 同构 + 全链 R16F + 显式统一 γ）
     → D ≤ 1 量化级（实测 unified profile 三档 dq 全 0，PASS），成本最高
性能成本 C(B)：随精度要求单调上升
  fp16 ALU 吞吐通常是 fp32 的 2×；R16F 带宽是 R11F 的 1.5~2×
```

两曲线交点附近取方案，按轴分别决策（三条轴量级差一个数量级以上，不必
一起升档）：

1. **γ 必须统一且显式写入效果文件**——零性能成本，消掉最大的误差项。
   不允许依赖任何平台的默认伽马。
2. **中间缓冲：tonemap 输出/合成链用 R16F**（保住低端和无钳制），
   bloom 下采样链可保留 R11F 但在 bright-pass 后做预钳到 64512 并对
   阈值比较留 margin。这是带宽与一致性的折中。
3. **计算精度：fp16 即可**，实测同构 fp16 三档 dq=0；只有跨平台
   归约顺序不同（box blur 的累加序）时才需要在累加变量上用 fp32。

## 5. 验收流程（三档块各跑一次）

1. 烧同一张测试图：三个已知亮度块 L ∈ {0.05, 0.5, 4.0}（线性光）。
2. 两平台各自过完整后处理链，输出转 8-bit 码值 `C_pc,k`、`C_con,k`。
3. 每档算 `dq_k`，全部 `dq_k ≤ 1` 才达标。
4. 超标的报告格式（程序已自动输出）：
   - 差异最大的亮度块名与 L 值；
   - 该平台对应的参数三元组 `(计算位宽, γ, 缓冲格式)`；
   - 按第 2 节判据标注根因 G/P，按第 3 节预算给出该参数的允许偏离量。

当前实测：仅统一 γ + 统一 R16F（允许 fp16）的 unified profile 达标；
as-shipped 组合（fp16 + γ 1.8 + R11F）low 块 dq=17，最差块为
low（L=0.05），主机参数 `fp16, γ=1.8, R11G11B10F`。
