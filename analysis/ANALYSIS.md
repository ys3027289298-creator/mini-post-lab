# 闪白事故分析：自动曝光的过冲—适应时间取舍

代码与图表：

- `eye_adaptation.py` — 模型与全部数值实验（`python3 -I eye_adaptation.py` 复现）
- `make_chart_data.py` / `chart_data.js` — 图表数据
- `eye_adaptation_chart.html` — 三面板交互图（过冲曲线 / 适应时间曲线 / 闪白回放，浅色+深色）

## 0. 模型

标准游戏眼适应（eye adaptation），全部控制在 log10 亮度域：

| 量 | 表达式 |
|---|---|
| 场景 log 亮度 | $L_t = \log_{10} Y_t$ |
| 平滑目标（boxcar 窗口 W 帧；W=0 即瞬时亮度） | $M_t = \frac{1}{W}\sum_{i=0}^{W-1} L_{t-i}$ |
| 目标曝光（K=0.18 为 key value） | $E_t^* = \log_{10}K - M_t$ |
| 适应回路（一阶 EMA） | $E_t = E_{t-1} + a\,(E_t^* - E_{t-1})$，$a = 1-e^{-\Delta t/\tau}$ |
| 显示值 | $D_t = R(Y_t\cdot 10^{E_t})$，R 为 Reinhard |

仿真参数：60 fps、τ=0.25 s（a=0.06449/帧，τ 合 15 帧）、1 JND=0.10 log10。
稳态工作点恒为 $R(K)=0.1525$，与场景亮度无关；Reinhard 在该点的小信号增益
$g(K)=d\log_{10}R/d\log_{10}v = 1/(1+K)=0.847$，即显示端 JND ≈ 曝光端 JND × 0.85。

## 1. 曝光收敛表达式：指数趋近，只滞后不过冲

目标阶跃到 $E_\infty^*$ 后，令 $e_t=E_t-E_\infty^*$：

$$e_t = (1-a)\,e_{t-1} \;\Rightarrow\; E(t)=E_\infty^*+\bigl(E_0-E_\infty^*\bigr)e^{-t/\tau}$$

- 一阶回路对**持续阶跃不会过冲**，误差按时间常数 τ 指数衰减：1τ 后残差 37%，3τ≈0.75 s 后 5%。
- 但每一帧都在滞后：阶跃首帧曝光还停在室内值，100× 阶跃时画面直接白 **7.85 JND**（10×/1000× 分别为 6.01/8.13 JND），之后指数恢复——这就是玩家看到的「白一下，约半秒」。实测进入 ±1 JND 带的时间：10× 0.567 s、100× 0.733 s、1000× 0.850 s（显示端口径 0.700 s）。
- 「过冲或滞后」的根源：τ 大则滞后久（白得久），τ 小则跟踪紧但对瞬时扰动毫无防御（见第 2、6 节）。

## 2. 过冲量成因：瞬时亮度做判据，一帧高光即可拉动目标

若收敛判据取**瞬时亮度**（W=0），开门那一帧的太阳/镜面高光使 $L$ 单帧跳变 $\Delta_s$，
目标曝光同步跳 $\Delta_s$ 并维持一帧。EMA 对单位帧脉冲的响应为 $a(1-a)^k$，峰值曝光偏差

$$\boxed{\;\Delta E_{\max}(W=0) = a\,\Delta_s\;}$$

即过冲量正比于那一帧的亮度跳变量 $\Delta_s$，比例系数为回路增益 a。
高光帧之后曝光被错误拉低，形成**暗反弹**（方向相反的次生过冲），按 $(1-a)^k$ 衰减。

加入 W 帧 boxcar 后，脉冲被摊成高度 $\Delta_s/W$、宽度 W 帧的矩形，级联 EMA 的峰值有解析式：

$$\boxed{\;\Delta E_{\max}(W) = \frac{\Delta_s}{W}\left[1-(1-a)^W\right]\quad (W\ge 1)\;}$$

- W ≪ τ_frames（15 帧）时 $(1-a)^W\approx e^{-W/\tau_f}$，窗口几乎不帮忙（W=1 与 W=0 同值）；
- W ≫ τ_frames 时退化为 $\Delta E_{\max}\approx \Delta_s/W$——正是「摊薄到每帧」的直觉式。

仿真与解析式在 W≥2 完全吻合（见脚本第 [2] 节输出）。

## 3. 用「过冲 ≤ 1 JND」反解平滑窗口最小长度

令 $\Delta E_{\max}\le J$（J=0.10 log10）：

- 渐近式（W≫τ_frames）：$W_{\min} \approx \Delta_s/J$，即 10× 高光→10 帧、100×→20 帧、1000×→30 帧；
- 精确解（有限 τ）：解 $\dfrac{\Delta_s}{W}(1-e^{-W/\tau_f})\le J$，因为括号 <1，实际 W_min 更小；
- 显示端判据再乘 g(K)=0.847，约束更松。

仿真反解（曝光端与显示端同时 ≤1 JND）：

| 单帧高光 Δs | 启发式 W_min=Δs/J | 实测 W_min | 说明 |
|---|---|---|---|
| 1.0（10×） | 10 | **0** | EMA 自身滤波已压到 0.60/0.52 JND，无需窗口 |
| 2.0（100×） | 20 | **10**（显示端 5） | 167 ms |
| 3.0（1000×） | 30 | **24** | 400 ms |

## 4. 取舍：适应时间与过冲幅度两条曲线（100× 亮度背景）

| W | 时长 | Δs=1 过冲 dE/显 (JND) | Δs=2 过冲 dE/显 | Δs=3 过冲 dE/显 | t_adapt 10×/100×/1000× (s) |
|---|---|---|---|---|---|
| 0 | 0 ms | 0.60 / 0.52 | 1.21 / 1.04 | 1.81 / 1.58 | 0.567 / 0.733 / 0.850 |
| 4 | 67 ms | 0.59 / 0.50 | 1.17 / 1.01 | 1.76 / 1.53 | 0.600 / 0.767 / 0.867 |
| 8 | 133 ms | 0.52 / 0.44 | 1.03 / 0.89 | 1.55 / 1.35 | 0.633 / 0.800 / 0.900 |
| **15** | **250 ms** | **0.42 / 0.36** | **0.84 / 0.72** | **1.26 / 1.09** | **0.700 / 0.867 / 0.967** |
| 24 | 400 ms | 0.33 / 0.28 | 0.66 / 0.57 | 1.00 / 0.86 | 0.783 / 0.967 / **1.067** |

窗口每加一帧，过冲单调下降、适应时间单调上升；W=15（=τ）是曲线拐点。
另一条杠杆是 τ 本身（W=0、Δs=1）：τ=0.10 s 时过冲 1.30/1.12 JND 但适应只要 0.283 s；
τ=0.50 s 时过冲 0.32/0.27 JND 但适应 1.483 s——同一条取舍曲线的不同参数化。

## 5. 三档亮度跳变实验与达标判定

判据：次生过冲 ≤ 1 JND（曝光端、显示端同时）**且** 适应时间 ≤ 1.0 s。

**常规高光（Δs=1，10×  glint）：W=0 即全部 PASS**，t_adapt 0.567/0.733/0.850 s。

**强高光（Δs=2，100× glint）：W≥10 全部 PASS**，t_adapt 0.650/0.817/0.917 s。

**极限压力（Δs=3，1000× glint）——出现不可同时满足区：**

| 阶跃 | 过冲达标窗口 | 该窗口下 t_adapt | 判定 |
|---|---|---|---|
| 10× | W≥24 | 0.783 s | PASS |
| 100× | W≥24 | 0.967 s | PASS（贴线） |
| 1000× | W≥24 | **1.067 s** | **FAIL** |

1000× 阶跃 + 1000× 单帧高光时两项判据冲突，明确报出**牺牲项：适应时间**——

- 守过冲：W=24，适应 1.067 s，超 1 s 预算 67 ms；
- 守时间：最大只能 W=18，此时过冲 1.16 JND（曝光端）/1.01 JND（显示端），双双超标。

## 6. 工程结论与建议

1. **根因**：目标亮度取瞬时值（W=0），开门帧的单帧高光按 $a\Delta_s$ 直接灌进曝光回路；
   而纯阶跃本身的 7.85 JND 首帧白是一阶回路滞后的固有现象，平滑窗口只能轻微改善、不能消除。
2. **推荐窗口 W=15 帧（250 ms，恰为一个 τ）**：常规与强高光（Δs≤2）下过冲 ≤0.84 JND，
   三档阶跃适应 ≤0.967 s，两条约束同时满足，处于取舍曲线拐点。
3. **极限场景不要靠继续加长窗口**（W=24 已突破 1 s 预算）。改用：
   - **直方图中值/众数做目标亮度**：小面积太阳高光几乎不移动中值，从源头拒绝单帧离群值
     （仓库 `tonemap/src/tonemap.c` 已有直方图基础设施，改造成本最低）；
   - 或时间域离群剔除（单帧亮度跳变限幅）后再进窗口；
   - 或非对称 τ：亮→暗与暗→亮使用不同时间常数，给闪白方向单独提速。
4. 直接闪光（高光帧本身 6+ JND 的白）任何曝光策略都无法消除，属于 tonemap 钳制与 bloom 阈值的职责范围。
