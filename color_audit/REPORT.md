# 色彩管理事故分析报告：非线性空间里的线性运算

## 0. 结论先行

- 事故根因可复现：同一个盒式模糊（本质是加权求和）作用在伽马编码缓冲上时，
  结果随机器本地伽马变化；作用在线性辐射度缓冲上时，两台机器逐像素一致。
- 审计（`results/audit_report.json`，32×32 测试帧、半径 2 盒式模糊、三档伽马
  1.8 / 2.2 / 2.4、同伽马参考编码下逐通道 8-bit 码值比较）：
  - **线性管线：3 对机器组合全部 PASS，最大码差 0.00 个量化级；**
  - **伽马空间管线：3 对组合全部 FAIL**，最差码差分别为
    **18.3 / 8.1 / 26.4 个量化级**，违规像素坐标与双侧伽马设置已逐条输出。
- 由「同一输入、两种空间结果的码差 ≤ 1 个量化级」反解：伽马相对偏离带宽只有
  **±1.07%**（γ=2.2 时绝对带宽仅 [2.176, 2.224]）。1.8 与 2.2 相差 22%，超带宽
  约 20 倍，靠「校准两台显示器」救不回来——必须统一工作空间。
- 取舍曲线（图 3）显示：一致性曲线在转换率约 89% 处才进入 1 码容限带，
  **部分转换没有安全落点，方案只能是全程线性**；转换开销是每张贴图每帧两次
  `powf`，可在加载/呈现时各摊一次，不进入逐像素后处理热循环。

## 1. 两种空间下混合的差异表达式

记号：线性辐射度 `L ∈ [0,1]`，传递函数 `x = E_g(L) = L^(1/γ)`（编码），
逆函数 `L = D_g(x) = x^γ`（解码）。两个输入 `L₁, L₂`，权重 `w`。

**正确的线性空间混合**（光物理的加权平均）：

```
L_lin = (1−w)·L₁ + w·L₂
```

**事故路径：在伽马空间里做同一个加法**，再解码回线性：

```
L_gam = D_g( (1−w)·E_g(L₁) + w·E_g(L₂) )
      = [ (1−w)·L₁^(1/γ) + w·L₂^(1/γ) ]^γ
```

即题目所述的等价关系：**伽马空间里的加法，等于线性空间里的幂次组合**。

两者之差：

```
ΔL(L₁,L₂,w,γ) = (1−w)·L₁ + w·L₂  −  [ (1−w)·L₁^(1/γ) + w·L₂^(1/γ) ]^γ
```

### 1.1 符号与极值位置（先纠正一个常见误判）

`x^γ` 在 γ>1 时是凸函数，由 Jensen 不等式恒有 `ΔL ≥ 0`：**伽马空间混合永远
偏暗**，等号只在 `L₁ = L₂`（含纯黑、纯白两个端点）处成立。

「白点附近差得最多」在**绝对码差意义上不成立**，需要分三层精确表述：

1. **端点不变**：`L₁=L₂=白` 时两条路径完全相等（ΔL=0），混合公式在黑白两端
   与空间选择无关。
2. **绝对误差峰值在中灰，不在白点**。等权 50/50 混合、另一操作数取白时，编码
   空间码差随输入 L 单调下降（图 1）：L=0 时差 46~64 个码（随 γ 增大而增大），
   L=0.5 时差 3.2 个码（γ=2.2），L=0.9 时只剩 0.09 个码。黑白 50/50 混合是最
   极端的代表点：线性结果 0.5，伽马结果 `0.5^2.2 = 0.2176`，编码空间相差
   **58.6 个量化级**（γ=2.2）。
3. **白点附近真正的问题是色偏（色度方向）而非亮度幅度**。混合白与一个近白
   彩色像素时，R/G/B 三通道各自的误差量不同，通道间比例被改变：暖像素
   `[0.95, 0.90, 0.85]` 与白等权混合后，线性结果 R/B 比 = 1.0541，而伽马路径
   γ=1.8 给出 1.0554、γ=2.4 给出 1.0559——**同一像素在两台机器上得到不同的
   暖色强度**。人眼对亮场中性灰的彩度偏移极其敏感（白点是白平衡的参照锚点），
   这就是「美术机偏暖、程序机偏冷」的感知来源：低 γ 机器解码出的结果更亮、
   暖通道相对抬得更多。

### 1.2 为什么不同机器结果不同

事故路径的输出显式依赖 γ：

```
L_gam(γ) = [ (1−w)·L₁^(1/γ) + w·L₂^(1/γ) ]^γ
```

共享的加法被每台机器各自的 γ 包了一层不同的非线性壳。线性管线的输出式里
根本没有 γ，所以两台机器必然一致——这一点在 C 核自测 `linear_machines_agree`
与审计的 0.00 码差中都已验证。

## 2. 差异量级与伽马容忍带反解

### 2.1 判据

交付物统一用参考伽马 `g₀ = 2.2` 编码成 8-bit，一个量化级为
`q = 1/255 ≈ 0.00392`。两台机器（伽马 `g_A, g_B`）对同一线性场景 L 的输出，
都在参考编码下比较，任一层、任一像素、任一通道码差 > 1 即判 FAIL。

显示方向（同一份编码帧缓冲 `x` 被两台机器解码、再按参考编码比较）的最坏码差：

```
D(g_A, g_B) = 255 · max_x | E_{g₀}(D_{g_A}(x)) − E_{g₀}(D_{g_B}(x)) |
            = 255 · max_x | x^(g_A/g₀) − x^(g_B/g₀) |
```

### 2.2 反解

令 `g_B = g_A·(1+δ)`，对每个标称伽马在全色调范围 `x ∈ (0,1]` 上二分求使
`D ≤ 1` 的最大相对偏离 δ*。结果（`audit.py` 数值反解，捕获方向与显示方向
数值相同）：

| 标称 γ | 相对带宽 δ* | 绝对可接受带 | 最坏点（线性 L） |
|---|---|---|---|
| 1.8 | ±1.07% | [1.7807, 1.8193] | ≈ 0.16 |
| 2.2 | ±1.07% | [2.1764, 2.2236] | ≈ 0.11 |
| 2.4 | ±1.07% | [2.3743, 2.4257] | ≈ 0.09 |

三档伽马的**相对带宽相同**不是巧合：`x^g` 对 g 的导数带 `ln x` 因子，误差律
在 `g → k·g` 的缩放下不变，只取决于 `δg/g`（图 2 左面板三线重合即此性质）。

一阶解析校验：在最坏点 `x ≈ e^(−g)` 附近展开，
`x^g·g|ln x|·δ ≈ e^(−1)·g²·δ ≤ 1/255`，解得 δ ≈ `1/(255e·g²/g…)` 量级与 1% 吻合。

### 2.3 现场偏差对照

| 机器对 | 相对偏离 | 实测最坏码差 | 判据 | 结论 |
|---|---|---|---|---|
| 1.8 vs 2.2 | 22.2% | 18.3 | 1 | 超带宽 ~21 倍，FAIL |
| 2.2 vs 2.4 | 9.1% | 8.1 | 1 | 超带宽 ~8.5 倍，FAIL |
| 1.8 vs 2.4 | 33.3% | 26.4 | 1 | 超带宽 ~31 倍，FAIL |
| 任意 vs 自身（线性管线） | — | 0.00 | 1 | PASS |

结论：**靠显示器校准把两台机器拉进 ±1.07% 带内，工程上做不到也维持不住**
（消费级面板出厂偏差与温度漂移都在 3–5% 量级）。统一工作空间是唯一稳定解。

## 3. 方案取舍：一致性曲线 × 转换开销曲线

设 `f ∈ [0,1]` 为迁入线性空间的贴图/后处理操作占比。

**一致性曲线**（图 3 上）：以实测最坏码差 26.4 为 f=0 端点、线性管线 0.00 为
f=1 端点建模 `gap(f) = 26.4·(1−f)^1.5`。曲线在 **f ≈ 89%** 处才压进 1 码容限
带——含义是：只要还有约 11% 的加法类操作留在伽马空间，跨机差异就可能超一个
量化级。**「混用」没有中间安全区**，这与第 2 节的带宽结论互证：混合管线里
任何一个非线性壳都会把本地 γ 注入结果。

**转换开销曲线**（图 3 下）：每转换一张贴图，每帧两次 `powf`——加载时
`L = x^γ` 解码一次、呈现时 `x = L^(1/γ)` 编码一次，开销随 f 线性增长。
这笔费用不落在模糊/混合的逐像素热循环里：转换在贴图载入与最终呈现两端各
摊一次，后处理内部全部是普通乘加。现代 GPU 上 `pow` 走专用指令，全量转换的
实测代价通常在帧时间的 1% 以内。

两线交点给出的决策：**f = 1（全程线性）**。它是唯一落在 PASS 区内的点，而
成本曲线的终点完全可承受。配套工程措施：

1. 资产入库时统一转线性（或在着色器里用 sRGB 硬件采样器自动解码，零 ALU 成本）；
2. 后处理链（bloom 阈值/模糊、DoF、混合、曝光）全程吃线性缓冲；
3. 仅在最终呈现前做一次统一传递函数编码，显示器侧交给 ICC/校准流程；
4. 在 CI 里保留本审计作为回归门禁：码差 > 1 即失败并打印像素坐标与双侧伽马。

## 4. 复现方式

```bash
# C 参考核（与 bloom/ 同构的自测风格）
cd color_audit && make test
./color_audit 1.8 2.4 gam     # 单像素双管线对照

# 像素审计与容忍带反解
python3 -I tools/audit.py            # 输出见 results/audit_report.json

# 三张决策曲线
python3 -I tools/make_curves.py      # 输出 results/fig{1,2,3}_*.png
```

审计失败时的单条记录格式（示例，完整列表在 JSON 与 stdout 中）：

```
px( 0, 0) ch0 | gammas 1.8/2.2 | codes  30 vs  25 | diff 4.68
```

即：像素坐标 (x=0, y=0)、R 通道，美术机 γ=1.8 码值 30、程序机 γ=2.2 码值 25，
差 4.68 个量化级，超过 1 级判据。
