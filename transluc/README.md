# transluc

半透明与景深的顺序冲突：两种顺序的要求表达式、错误范围、正确条件，以及深度精度取舍实验。`make test` 跑自检。

## 记号

- `O`：不透明通道，深度缓冲 `Z_o(p)`
- `T = {t_1..t_n}`：半透明层，合成顺序 `σ` 按深度远→近：`z_σ(1) ≥ … ≥ z_σ(n)`
- `D_z`：以深度 `z` 的弥散圆为核的散焦算子；`B`：over 混合；`C(p)`：像素最终颜色

## 两种顺序的要求与错误范围

**顺序甲（先景深后半透明）**：`C = B(T_σ, D_{Z_o}(O))`

- 要求：半透明在景深之后绘制 ⇔ `∀t∈T: CoC(z_t) ≡ 0`（半透明层等效永不散焦）。
- 错误范围：`E_甲 = { p ∈ ⋃ footprint(t) : CoC(z_t(p)) > 0 }`，误差幅度 `|D_{z_t}(t) − t|`。
  即**所有离焦半透明像素全部保持清晰**——半透明物不被模糊。

**顺序乙（先半透明后景深）**：`C = D_{Z′}(B(T_σ, O))`，其中 `Z′(p)` = 该像素最前表面深度

- 要求：每像素只有一个深度，散焦核由最前表面决定。
- 错误范围：`E_乙 = { p : 可见表面数 ≥ 2 ∧ z_front(p) ≠ z_back(p) }`，误差幅度
  `∝ |CoC(z_front) − CoC(z_back)|`。即**透过前景看到的背景被前景的 CoC 一起糊进来**。

## 正确做法的条件

半透明必须**参与景深的深度写入**，但**不参与与不透明通道的排序**：

```
∀t∈T:  t ∈ dom(Z_dof)            （半透明写入景深用的深度）
     ∧  SortKey(blend) = σ(T)     （混合只按半透明自身深度排序，不与 D 的输出重排）
C = B_{i=1..n}( D_{z_σ(i)}(t_σ(i)) )  over  D_{Z_o}(O)
```

每层用自己的深度决定自己的散焦，混合顺序不被景深输出污染。

## 由「穿透次数为零」反解深度精度

穿透 ⇔ 量化后保序失败：`∃ i≠j: z_i < z_j ∧ Q_b(z_i) ≥ Q_b(z_j)`。

零穿透的充要条件：`Q_b` 在层深度集合上严格保序 ⇔ 量化步长小于最小层间距：

```
Δ_b = (z_far − z_near) / (2^b − 1)  <  g_min = min_{i≠j} |z_i − z_j|
⇒  b ≥ b* = ⌈log2( (z_far − z_near)/g_min + 1 )⌉
```

## 取舍：穿透次数 × 带宽

- 带宽 `W(b) = n·b` bit/像素（n 层各存一份深度）；全精度（32 bit）排序准但带宽最高。
- 8 bit 省带宽，但层数一多 `g_min` 缩小，`Δ_8 > g_min`，出现穿透误判。
- 选 `min{ b : P(b) = 0 }`：实验对 4 / 16 / 64 层三档各跑 8/16/24/32 bit，
  输出每档的穿透次数与带宽曲线、所需精度 `b*`、以及发生穿透的两个物体编号。
