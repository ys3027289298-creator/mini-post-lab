# gridalias

棋盘格采样相位降采样伪影（QA「屏幕右半边细密网格纹」）的可复现分析与测量。

`make test`（或 `python3 -S src/grid_alias.py`）跑完整测量；加 `--plot` 额外输出
`src/visibility_bandwidth.png`（可见度/带宽两条曲线）与 `src/grid_heatmap.png`（屏幕固定网格）。

## 它回答的四个问题

1. **成因（采样相位）**：输出像素 m 采样源纹素
   `q_m = D·m + ε[m]`，`ε[m] = ε₀·(m mod 2)`。相邻像素从两个不同相位的子晶格取
   样，相位只依赖屏幕坐标 m，所以网格固定在屏幕上不随场景移动。
2. **周期 → 降采样因子**：分别在源缓冲与输出缓冲中**实测**主频 `f_src` 与混叠后
   `f_out = fold(f_src·D)`，搜索使 `fold(D·f_src) ≈ f_out` 成立的唯一整数 D（不依赖
   真值，非循环反解；对 D=2/3/4/6/8 盲测全部正确）。边带 `f_sb = 0.5 − f_out`，相位
   变换周期 `T_φ = 1/f_sb`，屏幕周期 `P = D·T_φ`，恒等式 `D = P/T_φ` 作为一致性闭合。
   三个镜头角度实测都反解出 `D = 4`。
3. **可见度 → 采样点数**：固定相位是相干误差，S=1 完全保留；多样本按 1/S（有序
   旋转网格，带抖动时约 1/√S）衰减。S=2 处于 Nyquist 临界，最坏对齐下仍可见
   （1.1–1.2% > 1% JND），即必须**超过单点采样的两倍**；解析最小为 S=3，但它贴在
   JND 边缘且 3 tap 不是硬件 MSAA 配置，工程上取 S=4。
4. **取舍**：可见度随 S 下降、带宽随 S 上升（单轴线性，2D pass 为 S²）。S=4 是在
   三档镜头角度上都带余量不可见的最小可实现（2 的幂）配置。

参数（降采样因子、JND、S=1 对比度、抖动量、三档空间频率）集中在
`src/grid_alias.py` 顶部，可按真机实测值替换。

> 模块搜索路径。
