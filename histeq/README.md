# histeq

直方图均衡的全局/局部失真归一化与切换阈值。

`make test` 跑自检，输出三档峰高的统一失真、切换阈值与算法选择。

## 推导

以输出级为单位（1 级 = 1 单位），探针直方图共 `M=16384` 计数，分布在 `N=256` 级上，
其中一级集中 `peak` 个计数，记 `pi = peak/M`。

**全局（HE）** — `out(i) = (N-1)·CDF(i)`，相邻级输出步长 `(N-1)·h(i)/M`。
峰两侧的稀疏肩部 `h=(M-peak)/(N-1)`，斜率从 1 压到 `1-pi`：

```
D_g = 1 - slope = pi                        [比例]
```

即"相邻级输出差 / 原始差"的比值减 1。

**局部（窗式/CLAHE）** — 保局部对比但边缘产生光晕：

```
D_l = R · C,  R 光晕半径[级], C 对比度提升[级/级]
```

窗口只能重分配它真正覆盖的动态范围；一级占去 `pi`，剩余 `1-pi` 同时限制半径与增益：

```
R(pi) = R_MAX·(1-pi),  C(pi) = C_MAX·(1-pi)
D_l(pi) = R_MAX·C_MAX·(1-pi)^2              [级]
```

## 归一化

两者量纲不同，各除以自身包络最大值（`pi∈[0,1]`）：

```
d_g(pi) = D_g / 1              = pi           ∈ [0,1]
d_l(pi) = D_l / (R_MAX·C_MAX)  = (1-pi)^2     ∈ [0,1]
```

统一失真 = 所选算法的归一化值，二者同尺度可直接比较。

## 切换阈值

令 `d_g = d_l`：

```
pi = (1-pi)^2  =>  pi^2 - 3pi + 1 = 0
pi* = (3-√5)/2 = 1/φ^2 = 0.381966...
peak* = pi* · M
```

`pi < pi*` 全局失真小；`pi > pi*` 局部失真小。

## 决策

每档取"成本可行算法中统一失真最小"者；需同时满足 `u ≤ U_MAX` 与 `cost ≤ BUDGET_MS`。
超出的档位报告峰高、`d_g`、`d_l` 与切换阈值位置。

当前参数（1080p，单遍）：`d_g=pi`、`d_l=(1-pi)^2`，`pi*=0.382`，`peak*=6258`；
`cost_global=1.14ms`、`cost_local=6.22ms`、`budget=5ms`、`U_max=0.40`。
