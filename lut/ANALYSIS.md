# LUT 三线性插值：误差界、感知度量与非均匀格点设计

配套代码：`src/lut.c`（8 角点三线性 + 均匀 FMA 快路径/通用二分路径）、
`src/lut_test.c`（自检）、`analysis/`（扫参实测与图表）。
所有数值均由 `make test` 与 `make bench` 实测，N = 17 格点/轴，
被逼近曲线 f(x) = x(1+k)/(x+k)，k = 0.18，感知度量为 CIELAB L*（D65），
可察觉阈值取 JND ΔE = 2.3。

## 1. 三线性插值表达式

格点 xᵢ = (x₀ᵢ, x₁ᵢ, x₂ᵢ)，i = (i₀,i₁,i₂)，格点值 L[i]。输入 x 落在
格胞 c = (c₀,c₁,c₂) 内，各轴分数坐标 tₐ = (xₐ − xₐ,cₐ)/(xₐ,cₐ+1 − xₐ,cₐ)，
权重 wₐ(0) = 1−tₐ、wₐ(1) = tₐ。三线性结果为 8 个角点的加权和：

```
P(x) = Σ_{d∈{0,1}³} [ ∏ₐ wₐ(dₐ) ] · L[c + d]
     = Σ_d (d₀?t₀:(1−t₀))(d₁?t₁:(1−t₁))(d₂?t₂:(1−t₂)) · L[c+d]
```

权重和恒为 1（8 项权重之和 = ∏ₐ[(1−tₐ)+tₐ] = 1），格点处精确（某个 tₐ=0 或 1
时只剩对应角点）——所以**测试期望值必须写在格点上**；写在格点上却拿插值结果
比对，差的就是下面这个余项。

## 2. 格点值与插值值的最大差

一维情形（三线性沿每个轴可分离，结论逐轴适用）：弦插值 P₁ 在格胞 [a,b] 上
的余项为

```
f(x) − P₁f(x) = ½ f″(ξ)(x−a)(x−b)
```

|x−a||x−b| 在 t = 1/2（格胞正中心）取最大 h²/4，h = b−a。
令格点值差 Δ = |f(b)−f(a)|，由中值定理 Δ = h|f′(η)|；配合余项式，
一维主阶误差界为 Emax = Δ/4，在格心取得。

推广到三维格胞。沿轴 a 的格点值差记 Δₐ = |L[..cₐ+1..] − L[..cₐ..]|，
定义该轴的参与系数

```
Cₐ = Δₐ / Δ,  Δ = Δ₀ + Δ₁ + Δ₂   （故 C₀C₁C₂ 为三向差的归一化乘积）
```

三线性是多线性映射，正中心 (t₀,t₁,t₂) = (1/2,1/2,1/2) 处每个轴的插值
各吃掉本轴格点差的 1/4，8 角点混合的最大偏差主项为

```
Emax(格心) = ¼ Δ · C₀C₁C₂
           = ¼ · (Δ₀/Δ)(Δ₁/Δ)(Δ₂/Δ) · Δ
```

即题目要求的形式：**相邻格点差值的四分之一，乘以三个方向的系数乘积**。
误差在每个轴都于 tₐ = 1/2 取极值，故整体最大值出现在格胞正中心。
可分离烘培（本模块，三轴共用一张一维节点值表）退化为一维：
只有一个轴的 Cₐ = 1、其余为 0，等价地 Emax = Δ/4。

两个实测注意点（`lut_test.c::trilinear_quarter_bound` 逐格验证）：

- 16 个格胞全部满足 Emax ≤ Δ/4，**实测峰值只到界的 29.75%**——Δ/4 是
  保守界，真实误差还乘了一个由曲率形状决定的小于 1 的因子。
- f″ 本身随 x 变化时，argmax 会从 t = 1/2 向曲率更大的低端轻微偏移
  （首格偏移约 0.037h，全部落在 t ∈ [0.4, 0.6] 内）；「最大误差在格心」
  是 f″ 常数时的严格结论，主阶位置不变。

## 3. 感知误差：暗部是亮部的多少倍

线性光域误差 E 换算成 L* 差。L*(Y) = 116 Y^(1/3) − 16，故

```
ΔL* ≈ (116/24) Y^(−2/3) · E
```

均匀格点 h 为常数，E ≈ |f″(Y)| h²/8（格心主阶），于是暗部 x_d 与亮部 x_b 的
感知误差之比

```
ΔL*(x_d)        (x_d)^(−2/3) |f″(x_d)|
──────── = ─────────────────────────────
ΔL*(x_b)        (x_b)^(−2/3) |f″(x_b)|

                  x_b 2/3   (x_b + k)³
            =  ( ───── ) · ( ───────── )
                  x_d       (x_d + k)
```

代入 x_d = 0.05、x_b = 0.50、k = 0.18：

```
解析倍数 = (10)^(2/3) · (0.68/0.23)³ = 4.64 · 25.9 ≈ 120×
实测倍数 = 3.001 / 0.0279 ≈ 108×
```

同一物理误差，暗部被 L* 的 Y^(−1/3) 响应放大两个数量级——这就是
「物理上均匀、感知上不均匀」的量化含义。均匀 LUT 暗部档实测 ΔL* = 3.001
> JND 2.3，物理峰值误差 0.0226；亮部档仅 0.028，差约 108 倍。

## 4. 反解非均匀格点分布

要求任一档位 ΔL* ≤ JND。把局部间距 h(x) 代入感知误差主阶：

```
(116/24) x^(−2/3) · |f″(x)| · h(x)²/8 ≤ JND
```

反解出间距律

```
                ⎡      8 · JND                    ⎤ 1/2
h(x) ≤  h_JND(x) = ⎢ ───────────────────────────── ⎥
                ⎣ (116/24) x^(−2/3) |f″(x)|        ⎦
```

设格点按幂律 xᵢ = (i/(N−1))^p 分布，其局部间距为

```
h(x) = p x^(1−1/p) / (N−1)
```

在暗部 x = 0.05 处令 h(x) = h_JND(x)：

- 数值反解（本曲线、N=17）：h_JND(0.05) = 0.0430，对应 **p\* ≈ 1.25**；
- 小 x 极限：f″ ≈ 2/k 为常数，h_JND ∝ x^(1/3)，与 h(x) ∝ x^(1−1/p)
  比较指数得 1 − 1/p = 1/3，即 **p → 3/2**。间距随 x^(1/3) 增长——
  暗部最密、亮部最疏，密度正比于感知权重 x^(−1/3)。
- 实测 crossing（密集重采样，`analyze.py`）在 **p ≈ 1.06**，比线性化解析值
  更早达标，因为 Y^(−2/3) 的一阶展开在暗部偏保守。设计取 **p = 1.3**
  留安全边际，而不是直接贴 crossing。

### 暗部与亮部的格点间距比

幂律的局部间距比（x_d = 0.05、x_b = 0.50，p = 1.3）：

```
h(x_d)/h(x_b) = (x_d/x_b)^(1−1/p) = 0.1^(1−1/1.3) ≈ 0.59
```

首末两个格胞的有限差分间距（`make test` 打印值）：

```
h₀ = 1/16^1.3 = 0.02720,   h_L = 1 − (15/16)^1.3 = 0.08048
首尾比 h₀/h_L ≈ 0.338
```

p 越大暗端越密、亮端越疏；首尾比随 p 单调恶化（见报告图②与 sweep.csv），
这是 p 不能无限加大的真实代价。

## 5. 取舍：两条曲线如何定格点分布

`analysis/report.html`（`make bench` 后由 `analyze.py` 生成）给出三条曲线：

| 曲线 | 随 p 的行为 | 含义 |
|---|---|---|
| 各档 ΔL*（图①） | 暗部从 3.00 骤降到 p≈1.1 的 1.67，之后边际收益迅速递减 | 误差曲线在 p≈1.1–1.3 出现拐点 |
| 暗/亮格间距与首尾比（图②，对数轴） | 暗端 h₀ 持续缩小，亮端 h_L 持续增大，首尾比 1 → 6.7e-4 | p 过大等于把亮部格点掏空 |
| 查表耗时（图③） | 通用二分路径 30–35 ns，**与 p 无关**；均匀 FMA 快路径 17 ns 仅 p=1 可用 | 非均匀是约 1.8× 的固定「进门费」，不随 p 增长 |

二分深度只取决于 N（⌈log₂17⌉ = 5 次比较），所以查表开销是阶跃的一次性
代价，而亮部失真随 p 连续恶化。最优策略是取**满足暗部 JND 的最小 p**：
解析 p\* ≈ 1.25、实测 crossing ≈ 1.06，设计点定 **p = 1.3**。

## 6. 三档亮度实测（N=17，窗口 ±0.02）

| 档位中心 | 均匀 ΔL* | p=1.3 ΔL* | 判定 |
|---|---|---|---|
| 0.05（暗） | **3.001** | 0.741 | 均匀超标，非均匀达标 |
| 0.18（中） | 0.308 | 0.172 | 均达标 |
| 0.50（亮） | 0.028 | 0.033 | 均达标（非均匀略升，仍远低于 JND） |

超标档（均匀 LUT 暗部）按要求给出的实测数据：

- 实测感知误差：**ΔL\* = 3.001**（阈值 2.3，超出 30%），物理峰值误差 0.0226；
- 亮暗两端格点间距：均匀律下均为 **h = 1/16 = 0.06250**；
- 建议间距比：幂律 p = 1.3，局部间距比 **h_dark/h_bright ≈ 0.59**
  （首末格胞有限差分为 0.02720 / 0.08048 ≈ 0.338），改造后该档 ΔL* 降到 0.74。

## 7. 对单元测试的修复原则

旧测试把离散格点常数当作任意输入的期望值，与插值实现天然不符。
`lut_test.c` 改为三类可证明的断言：

1. **格点精确**：在 xᵢ 上采样与参考曲线误差 < 1e-6（两种间距律都查）；
2. **界内插值**：逐格扫描，离格点误差 ≤ Δ/4 界，且 argmax 落在格心邻域；
3. **感知达标**：三档 ΔL* 对照 JND，均匀暗部允许失败但必须打印实测值，
   非均匀 LUT 三档必须全过。

这样测试从「常年红着没人管」变成对推导结论的可执行验证。
