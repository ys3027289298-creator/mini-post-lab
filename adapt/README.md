# adapt

暗适应建模 + 局部曝光统计窗口标定。`make test` 跑自检并对三档洞穴尺寸各跑一次窗口求解。

## 1. 暗适应：感知亮度 vs 物理亮度

视觉系统对亮度的响应是分段对数（Fechner），感知阈值随暗适应时间指数下降：

```
L_th(t) = L_inf + (L_0 - L_inf) * e^(-t/tau)        感知阈值
P(L,t)  = k * max(0, ln(L / L_th(t)))               感知亮度
```

`L_0` 是明适应阈值（刚进洞），`L_inf` 是完全暗适应阈值，`tau` 是适应时间常数。
进入洞穴瞬间阈值还挂在 `L_0`，只要角色显示亮度 `L_c*E < L_th(t)`，感知输出就是 0
——这就是「统计均值不低但观众觉得瞎」：均值不低是物理量，瞎是阈值没跟上。
角色重新可见的时刻：

```
t_vis = tau * ln((L_0 - L_inf) / (L_c*E - L_inf))
```

## 2. 全画面平均曝光的区域偏差

曝光按全画面均值取 `E = L_key / L_bar`，`L_bar = sum(f_i * L_i)`（`f_i` 为各类
表面的像素占比）。角色处显示亮度为 `L_c * L_key / L_bar`，偏差（档）：

```
Delta = log2(L_bar / L_c) = log2(1 + f_w * (L_w/L_c - 1) + ...)   (岩壁占比 f_w)
```

洞穴里大片岩壁（`L_w >> L_c`）把 `L_bar` 拉高，`Delta` 可到 2.5 档以上，
角色附近被压到阈值以下。

## 3. 用 1 JND 反解窗口

可察觉级按 Weber 分数 `k_w = 0.02`，对数域 `JND = ln(1 + k_w)`。
设角色邻域（半径 `R_V` 的圆盘）实测均值为 `L_V`，半径 `w` 的统计窗口均值
在圆盘几何下（`w > r_f`，`r_f` 为暗色地面半径）：

```
L(w) = L_w - (L_w - L_f) * (r_f / w)^2
```

要求局部统计相对真值偏差不超过 1 JND：`|ln(L(w)/L_V)| <= JND`，反解：

```
w <= r_f / sqrt(1 - k_w * L_f / (L_w - L_f))     （岩壁侵入上界）
```

## 4. 取舍：精度曲线 vs 稳定性曲线

- 精度 `e_acc(w) = |ln(L(w)/L_V)|`：U 形，零点在 `w = R_V`，小了被角色自身
  拉偏，大了被岩壁侵入。
- 稳定性 `e_stab(w)`：镜头抖动 ±D_cam 下统计量的对数标准差，叠加角色动画项
  `A * L_c * (R_c/w)^2 / L(w)`（窗口越小角色占比越高，动画一帧统计量就跳）。
  平移项只在窗口边缘扫过亮度边界（`w ± D_cam` 跨过 `R_c` 或 `r_f`）时爆发。

可行集 `{e_acc <= JND} ∩ {e_stab <= JND}`，取离 `R_V` 最近的 `w*`；
交集为空则取 `min max(e_acc, e_stab)` 的折中点并判该档超标。

## 5. 三档洞穴实测

`src/adapt.c` 合成 256x256 洞穴画面（角色 0.05 / 地面 0.10 / 岩壁 0.55±15% /
洞口 2.5），三档仅改暗区半径 `r_f = 19.5 / 30 / 48`。每档输出窗口 `w*`、
角色周围与全画面实测亮度及比值、两条曲线的 JND 倍数、全局/局部曝光下角色
重新可见时间 `t_vis`。
